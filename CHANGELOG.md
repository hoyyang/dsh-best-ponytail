# Changelog

## 0.1.0 (2026-09-20)

- Initial packaging of upstream ponytail (commit e3ba2aa, 2026-09-14) as a DSH bundle plugin.
- 6 bundled skills served via `ctx.skills` provider; `/ponytail` session command; optional always-on ruleset injection via `ctx.systemPrompt` section (config `mode`, default off).
- Full upstream tree vendored verbatim under `upstream/`.
